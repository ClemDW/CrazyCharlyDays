Self-Hosted Runner

Machine personnelle connectée au réseau eduroam (WiFi universitaire). Nécessaire car Docketu n'est pas accessible depuis Internet, uniquement depuis le réseau universitaire. Le runner exécute les jobs GitHub Actions localement.

Clé SSH — Runner → Docketu SSH

La clé privée est stockée dans les GitHub Secrets (DOCKETU_SSH_PRIVATE_KEY). Au runtime, elle est écrite dans ~/.ssh/id_ed25519 sur le runner pour se connecter à Docketu. La clé publique correspondante est dans authorized_keys du user Docketu.

Clé SSH — Docketu → GitHub Git

Le user denis154u sur Docketu possède une clé SSH dont la partie publique est enregistrée sur GitHub (Deploy Key ou clé SSH du compte). Cela permet le git clone / git pull via SSH depuis Docketu.

Réseau Universitaire Réseau

Docketu est isolé sur le réseau interne de l'université. Le self-hosted runner doit être sur eduroam pour atteindre le serveur. C'est la contrainte qui impose l'utilisation d'un runner auto-hébergé plutôt que les runners cloud de GitHub.
